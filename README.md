# SEWLAND RPG ⚔️

Консольная текстовая RPG на чистом Python.
Пройти испытание, победить врагов, набрать опыт и попасть в город SEWLAND.

## Геймплей
- Создание героя
- Пошаговые бои со случайным уроном
- Выбор: атака или защита
- Система опыта и переход на новый уровень
- Восстановление здоровья

## Запуск
```bash
python sewland.py
